# Observatory Design System — Phase 5: Editorial Language

**Status:** Governing standard. Extends Phases 1–4; does not replace them. All prior rules remain in force.
**Date:** 2026-06-25 · authored from the established system.

> Phase 5 governs **words**: voice, the canonical lexicon, naming, and microcopy. It is largely a writing standard (little code). Existing copy converges to it page-by-page (staged, logged); the wordmark casing is protected identity and never changes.

---

## 1. Voice (carried forward, made explicit)
The platform speaks as a **calm, senior, evidence-led executive institution** — never a vendor. Qualities: **calm · premium · editorial · trustworthy · evidence-led · timeless · executive.**

- **MUST** write for a busy senior leader: lead with the decision-relevant point; respect attention.
- **MUST** be plain and precise. Short sentences. Concrete nouns. Active voice.
- **NEVER** hype, hard-sell, or use vendor-marketing language ("revolutionary", "cutting-edge", "unlock", "supercharge", "game-changer", "10x").
- **NEVER** use exclamation marks in product copy; no emoji.
- **MUST** be confident without overclaiming — state evidence and limits honestly (matches the hero standfirst: *"Most organisations don't have an AI problem. They have a Decision Performance problem."*).

## 4. Microcopy standards
- **CTAs — verb-led, specific, no fluff.** Good: *"Find your primary constraint"*, *"Take the Decision Performance Index"*, *"See where your organisation stands"*. Avoid: *"Learn more"*, *"Click here"*, *"Get started"*.
- **Labels / eyebrows — mono, UPPERCASE, terse** (the `--type-label` role): category · date · read-time.
- **Empty states — calm and directive**, not apologetic: *"Intelligence incoming — the first approved insights will appear here."* State what will happen, not "nothing here".
- **Error states — plain, blame-free, actionable**: say what happened + the next step; never expose internals; no "Oops!".
- **Loading — quiet and factual**: *"Loading signals…"* — never playful or jargon-as-drama.
- **Numbers / scores:** integer scores as `47 / 100`; percentages with `%`; dates `23 Jun 2026`; en dash for ranges; one decimal only where it earns it.
- **Sentence case** for body, descriptions, UI controls; **title case** only for proper product names and the pillars/dimensions.

## 5. Accessibility of language
Plain, scannable, front-loaded. Define a term on first use. Link text describes its destination (never "here"). Reading level: senior-generalist, not academic; no unexplained acronym on first use (DPI → spell out once).

## 6. Governance
- **MUST** run new customer-facing copy against this standard (voice + lexicon + microcopy) before publish.
- **NEVER** introduce a new product/category name without ratification (as templates §8.0 / components §9).
- Retired terms are debt: log and converge, don't silently rewrite legacy outside the page being worked.
